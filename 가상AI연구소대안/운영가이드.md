# SNST RND CENTER 운영 가이드

## 현재 구성: 단일 계정 + 태그 기반 관리

### 운영 원칙

1. **단일 Ollama 계정**으로 모든 AI 에이전트 운영
2. **태그 기반 구분**으로 에이전트별 모델 식별
3. **나중에 필요시** 에이전트별 계정 분리 가능

---

## 모델 실행 가이드

### 1. Ollama 설치

```bash
# Ollama 설치 (Windows/Mac/Linux)
# https://ollama.com/download

# 버전 확인
ollama --version
```

### 2. 모델 다운로드

```bash
# 기본 모델 다운로드
ollama pull qwen2.5:7b
ollama pull qwen2.5:14b

# 태그를 활용한 모델 관리
ollama tag qwen2.5:7b qwen2.5:7b-rtl
ollama tag qwen2.5:7b qwen2.5:7b-verification
```

### 3. 에이전트별 실행

```bash
# 연구소장 AI
ollama run qwen2.5:14b

# RTL 엔지니어 AI
ollama run qwen2.5:7b-rtl

# 검증 엔지니어 AI
ollama run qwen2.5:7b-verification

# PNR 엔지니어 AI
ollama run qwen2.5:7b-pnr

# QA 엔지니어 AI
ollama run qwen2.5:7b-qa

# 문서화 AI
ollama run qwen2.5:7b-docs
```

### 4. 실행 상태 확인

```bash
# 실행 중인 모델 확인
ollama ps

# 모델 목록 확인
ollama list
```

## 업그레이드 시나리오

나중에 에이전트별 계정 분리 시:

### 1. Docker 기반 격리

```bash
# 에이전트별 컨테이너 생성
docker create --name rtl-agent ollama run qwen2.5:7b-rtl
docker create --name verif-agent ollama run qwen2.5:7b-verification
```

### 2. 사용자 계정 분리

```
Linux 사용자 생성:
sudo useradd -m rtl-engineer
sudo useradd -m verif-engineer

각 사용자에게 모델 디렉토리 할당
```

### 3. 리소스 제한 (cgroups)

```
각 에이전트의 VRAM/RAM 사용량 제한
```
