# SNST RND CENTER 대안

상용 API 대신 로컬에서 AI를 실행하는 방법들을 정리함.

## 로컬 LLM 솔루션

### Ollama

- 로컬에서 LLM을 실행할 수 있는 도구
- 설치만 하면 바로 사용 가능
- 주요 모델: Llama 3, Qwen, Mistral 등
- URL: https://ollama.com

### LM Studio

- 데스크톱용 LLM 실행 앱
- GUI로 모델 관리 가능
- URL: https://lmstudio.ai

## 추천 모델

| 모델 | 크기 | VRAM 요구량 | 성능 |
|------|------|-------------|------|
| Qwen2.5-7B | 7B | 8GB | 상용 수준 |
| Llama3-8B | 8B | 10GB | 높음 |
| Qwen2.5-14B | 14B | 16GB | 매우 높음 |
| Mistral-7B | 7B | 8GB | 상용 수준 |

```
┌─────────────────────────────────────────┐
```

## 시작 방법

1. Ollama 설치 (Windows/Mac/Linux 지원)
2. 터미널에서 `ollama run qwen2.5` 실행
3. Python으로 API 호출하여 에이전트 연결
