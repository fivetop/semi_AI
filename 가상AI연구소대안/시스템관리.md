## 2. AI 모델 관리

### 2.1 모델 설치 및 버전

| 항목 | 확인 방법 | 조치 |
|------|----------|------|
| 설치된 모델 목록 | `ollama list` | 불필요 모델 삭제 |
| 모델 버전 업데이트 | `ollama pull <모델명>` | 주기적 업데이트 |
| 양자화 설정 | `ollama show <모델명>` | Q4_K_M 확인 |

### 2.2 모델 실행 상태

```bash
# 실행 중인 모델 확인
ollama ps

# 모델 중지
ollama stop <모델명>

# 모델 재시작
ollama run <모델명>
```

### 2.3 모델 관리 규칙

- **일일**: 실행 상태 확인
- **주간**: 불필요 모델 정리
- **월간**: 모델 업데이트 및 최적화

## 3. 소프트웨어 관리

### 3.1 Ollama 관리

| 항목 | 확인 방법 | 조치 |
|------|----------|------|
| Ollama 버전 | `ollama --version` | 최신 버전으로 업데이트 |
| 실행 상태 | `ollama ps` | 문제 시 재시작 |
| 로그 확인 | `tail -f ~/.ollama/logs/server.log` | 에러 확인 |

### 3.2 Python 환경

| 항목 | 확인 방법 | 정상 기준 |
|------|----------|----------|
| Python 버전 | `python --version` | 3.10 이상 |
| pip 패키지 | `pip list` | 필수 패키지 설치 |
| 가상환경 | `conda env list` 또는 `python -m venv` | 필요 시 생성 |

### 3.3 필수 도구 설치 체크리스트

```
□ Ollama 설치 및 실행
□ Python 3.10 이상 설치
□ Git 설치 (버전 관리용)
□ VS Code 설치 (편집기)
□ 필수 Python 패키지 (requests, openai 등)
```

### 3.4 업데이트 일정

| 항목 | 주기 | 방법 |
|------|------|------|
| Ollama | 월 1회 | `ollama upgrade` |
| Python 패키지 | 월 1회 | `pip list --outdated` |
| 시스템 업데이트 | 분기 1회 | OS 업데이트 |
