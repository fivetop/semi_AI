# SNST RND CENTER 웹 개발 계획

React + Node.js 기반 업무 관리 시스템 개발 계획.

---

## 1. 개발 목표

SNST RND CENTER의 조직도를 기반으로 한 웹 기반 업무 관리 시스템 구축

## 2. 기능 목록

### 2.1 핵심 기능 (필수)

| 기능 | 우선순위 | 설명 |
|------|----------|------|
| **조직도 뷰** | 1순위 | 팀 구조 시각화 (팀장, 팀원 표시) |
| **업무 관리** | 2순위 | 할일 생성, 할당, 진행 상황 추적 |
| **AI 모니터링** | 3순위 | 에이전트 실행 상태, VRAM 사용량 |

### 2.2 추가 기능 (선택)

| 기능 | 우선순위 | 설명 |
|------|----------|------|
| **문서 관리** | 4순위 | 프롬프트 템플릿 저장, 버전 관리 |
| **일정/마일스톤** | 5순위 | 프로젝트 마감일, 알림 |

## 3. 기술 스택

### 3.1 프론트엔드

```
React 18+
  ├── React Router (SPA 라우팅)
  ├── Tailwind CSS (스타일링)
  └── Recharts (차트/그래프)
```

### 3.2 백엔드

```
Node.js + Express
  ├── SQLite (데이터 저장)
  └── Socket.io (실시간 통신)
```

## 4. 데이터베이스 설계

### 4.1 사용자 (Users)

| 필드 | 타입 | 설명 |
|------|------|------|
| id | INTEGER | 고유 ID |
| name | TEXT | 이름 |
| role | TEXT | 직책 (팀장, 연구원 등) |
| team | TEXT | 팀 (전략 기획, 기술 연구, 사업 개발) |
| email | TEXT | 이메일 |

### 4.2 업무 (Tasks)

| 필드 | 타입 | 설명 |
|------|------|------|
| id | INTEGER | 고유 ID |
| title | TEXT | 업무 제목 |
| description | TEXT | 업무 설명 |
| assignee_id | INTEGER | 담당자 ID |
| status | TEXT | 상태 (진행중, 완료, 대기) |
| priority | TEXT | 우선순위 (높음, 중간, 낮음) |
| due_date | DATE | 마감일 |

### 4.3 AI 에이전트 (AI Agents)

| 필드 | 타입 | 설명 |
|------|------|------|
| id | INTEGER | 고유 ID |
| name | TEXT | 에이전트 이름 |
| role | TEXT | 역할 (RTL, 검증, PNR 등) |
| status | TEXT | 상태 (실행중, 대기, 중지) |
| vram_usage | INTEGER | VRAM 사용량 (MB) |

## 6. 개발 일정

### 1단계 (1~2주)

- 프로젝트 설정
- React + Node.js 기본 구조
- SQLite 데이터베이스 연동

### 2단계 (3~4주)

- 조직도 화면 개발
- 사용자 CRUD 기능

### 3단계 (5~6주)

- 업무 관리 기능
- 상태 변경 로직

### 4단계 (7~8주)

- AI 모니터링 연동
- 실시간 상태 업데이트

### 5단계 (9~10주)

- 문서 관리 (선택)
- 일정 기능 (선택)
- 테스트 및 배포

## 7. 배포 옵션

| 옵션 | 설명 |
|------|------|
| **로컬 서버** | 사내 서버에서 직접 운영 |
| **클라우드** | AWS, GCP, Vercel 등 |
| **컨테이너** | Docker로 패키징 후 배포 |
