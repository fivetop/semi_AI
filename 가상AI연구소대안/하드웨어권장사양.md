# SNST RND CENTER 하드웨어 사양 권장안

SNST RND CENTER에서 AI 에이전트를 운영하기 위한 하드웨어 사양을 정리함.

---

## 1. 기본 기준

로컬 LLM 실행 시 가장 중요한 요소는 **VRAM (GPU 메모리)** 임.

| 모델 크기 | VRAM 요구량 | 적용 GPU |
|-----------|-------------|--------------|
| 7B (Q4 양자화) | 5~6 GB | RTX 3060 8GB 이상 |
| 14B (Q4 양자화) | 10~12 GB | RTX 4070 12GB 이상 |
| 32B (Q4 양자화) | 20~24 GB | RTX 4090 24GB |
| 72B (Q4 양자화) | 40~48 GB | Dual GPU 또는 Apple Silicon |

## 3. SNST RND CENTER 권장 구성

14명 연구소 기준, 동시에 6개 AI 에이전트 운영 시:

| 구분 | 권장 사양 | 이유 |
|------|----------|------|
| **CPU** | i7-13700 이상 | 8코어 16스레드, 다중 처리 |
| **RAM** | 64GB | VRAM 부족 시 시스템 메모리 활용 |
| **GPU** | RTX 4070 Ti 12GB x 1대 | 14B 모델 1개 + 7B 모델 2개 동시 실행 |
| **저장소** | 2TB SSD | 모델 파일 저장 (약 20~30GB) |

**총 예상 비용: 약 250만원**

---

## 4. 확장 옵션

### 4.1 다중 GPU 구성

```
RTX 4090 24GB x 2대 = 48GB VRAM
→ 32B 모델 + 14B 모델 동시 실행 가능
→ 약 500만원 추가
```

### 4.2 클라우드 하이브리드

- 일상적으로는 로컬 (7B/14B 모델)
- 대규모 프로젝트 시 클라우드 VM 활용 (A100 대여)
- 비용 절감 + 성능 유연성

---

## 5. 운영 권장사항

### 5.1 동시 실행 관리

```
GPU VRAM 12GB 기준:
├── 연구소장 AI: Qwen2.5-7B (5GB)
├── RTL 엔지니어 AI: Qwen2.5-7B (5GB)
└── 검증 엔지니어 AI: Llama3.1-8B (5GB) - 순차 실행 필요
```

### 5.2 모델 선택 가이드

| 용도 | 추천 모델 | VRAM |
|------|----------|------|
| 일반 대화 | Qwen2.5-7B | 5GB |
| 코드 생성 | DeepSeek-Coder-6.7B | 4GB |
| 복잡한 추론 | Qwen2.5-14B | 10GB |
| 다국어 | Llama3.1-8B | 5GB |

### 5.3 성능 최적화

- **양자화**: Q4_K_M 선택 (품질/속도 균형)
- **컨텍스트 길이**: 4096~8192 토큰으로 제한
- **KV 캐시**: 충분히 할당
