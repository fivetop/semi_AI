# AI 개발 용어 정리

---

## PART A: 환경 (Environment)

| 용어 | 영어 | 설명 |
|------|------|------|
| **IDE** | Integrated Development Environment | 통합 개발 환경 - 코딩, 디버깅, 실행을 하나의 도구에서 수행 |
| **CLI** | Command Line Interface | 터미널/명령줄 인터페이스 - 텍스트로 명령을 입력하는 방식 |
| **Model** | - | AI 모델 - 학습된 신경망으로 입력에 대한 출력 생성 |

---

## PART B: AI 기초 (AI Fundamentals)

| 용어 | 영어 | 설명 |
|------|------|------|
| **Prompt** | - | 프롬프트 - AI에게 보내는 명령/질문 |
| **Context Window** | - | 컨텍스트 윈도우 - AI가 한 번에 처리할 수 있는 토큰 범위 |
| **Token** | - | 토큰 - 텍스트最小的 단위 (단어, 단어 일부, 문자) |
| **Hallucination** | - | 할루시네이션 - AI가 사실이 아닌 내용을 생성하는 현상 |

---

## PART C: 프로젝트 설정 (Project Setup)

| 용어 | 영어 | 설명 |
|------|------|------|
| **PRD** | Product Requirements Document | 제품 요구사항 문서 - 프로젝트 목표와 기능 정의 |
| **Rule File** | - | 룰 파일 - AI 행동 지침을 담은 설정 파일 |
| **API** | Application Programming Interface | API - 프로그램 간 통신을 위한 接口 |
| **MCP** | Model Context Protocol | 모델 컨텍스트 프로토콜 - AI가 외부 도구에 접근하는 标准 |

---

## PART D: 에이전트 시스템 (Agent System)

| 용어 | 영어 | 설명 |
|------|------|------|
| **Agent** | - | 에이전트 - 목표를 위해 자율적으로 행동하는 AI |
| **Skill** | - | 스킬 - 특정 작업 수행 능력 (예: Git, 브라우저 자동화) |
| **Hook** | - | 훅 - 특정 시점에 실행되는 사용자 정의 로직 |
| **Orchestration** | - | 오케스트레이션 - 여러 에이전트/컴포넌트 조율 |
| **Multi-Agent** | - | 멀티 에이전트 - 여러 에이전트가 협력하는 시스템 |

---

## PART E: 코드 관리 (Code Management)

| 용어 | 영어 | 설명 |
|------|------|------|
| **Debug** | - | 디버그 - 코드 오류 찾고 수정하는 과정 |
| **Git** | - | Git - 버전 관리 시스템 (코드 변경 추적) |
| **Deploy** | - | 디플로이 - 프로그램을 서버에 배포 |
| **Sandbox** | - | 샌드박스 - 테스트용 격리 환경 |
